UKgent Privacy Policy

Last updated: 3 November 2026

UKgent is a personal tool used by a single person to manage their own YouTube channel. This policy explains what information the tool handles.

Information accessed

When its owner signs in with Google, UKgent requests permission to: upload videos to the owner's YouTube channel; read the owner's video statistics; and read and reply to comments on the owner's videos. It accesses only the owner's own channel and nothing belonging to other people.

How it is used

This access is used only to publish and manage the owner's own videos and to help draft replies to comments on them. Comment text is processed to draft replies and is not used for anything else.

Storage and sharing

The sign-in credential (a refresh token) is stored as an encrypted secret in the owner's private code repository. Video statistics and a list of videos made are kept in that same private repository. UKgent does not sell, rent or share Google user data with anyone, does not use it for advertising, and does not transfer it to other parties, except that comment text is sent to an AI model provider solely to draft a reply for the owner.

Google API Services User Data Policy

UKgent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke UKgent's access at any time at myaccount.google.com/permissions and can delete the stored credential and data by deleting the repository secrets and repository.
